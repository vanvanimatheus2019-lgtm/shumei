## 配音与画面

演示视频使用 Windows 自带 Microsoft Huihui Desktop 中文合成语音，经语速处理和逐句停顿后合成。它不属于团队真人录音。字幕与旁白内容一致，保留独立 WAV 和 SRT，方便团队替换为真人讲解。

曾准备尝试 Microsoft Edge 在线神经语音。自动审批认为发送完整项目旁白到该外部服务缺少明确授权，拒绝执行；文本未发送，本版保留本机语音，没有绕行或重试。

画面使用本次项目的实际浏览器界面截图与操作状态。地图影像的来源、时间和范围以项目的数据说明为准。机制示意必须标明用途，不能被当作历史实拍。人物故事与影像观测窗口分别呈现，不据此认定观测窗口属于人物个人林地。

旧工程中背景音乐及部分照片的授权情况未核实，因此本版演示视频不采用这些素材。视频无背景音乐。此处理不代表其他素材的版权已经完成核验。

当前视频文件为 `presentation/演示视频_合成配音版.mp4`，实际时长 285 秒（4 分 45 秒），1920×1080、25 fps。画面重新捕获自本轮最终 GitHub 整合页面，包括横山 1986-08-02 / 2025-08-13 首屏、实景序章、石光银行动、区域时间轴、盐池四期配对与同步观察框，已替换此前页面不一致的示范片。

48 句旁白使用 Windows Microsoft Huihui Desktop 合成语音：31 句复用 V2 同文音频，17 句在本机新增，未向外部语音服务发送文本。它不是团队真人录音。独立 SRT、画面内字幕与字幕轨按实际旁白时序生成。制作检查包括完整解码、时长与流格式、黑屏检测、音量采样、关键画面抽查，以及本地浏览器播放/拖动和 HTTP Range；这些不等于团队已完整听看或完成人工内容审核。

网页仓库现包含 MP4、SRT、制作说明和验证记录。逐句音频、合成脚本、时序、实际界面截图、操作帧与联系表保留在本地交付目录 `qa/github-video`。照片与旧背景音乐的许可状态没有因视频重录自动变更；视频未加入旧背景音乐。

本轮校验发现横山显示图和四张人物照片含附加的 C2PA 元数据，旧台账未计入这些数据。仅在内存中进行分块比较后，剩余字节 SHA 与旧记录完全一致；已按完整发布文件更新台账，并保留原文件和全部元数据。校验一致不能替代来源、数值与许可核验。

本轮保留已有背景音乐文件，旧背景音乐的授权状态仍未核实。新闻照片已经公开发表并保留署名，也不代表取得转载许可。正式使用前需据实记录适用许可、取得授权或替换素材。不要将这些待办写成已经完成。

原全区 1986—2025 年四组年度数组沿用原工程。约 69% 描述共同有效图像像元中近似 NDVI 差值超过 0.1 的计数比例；没有地面面积加权，不能称为“69% 的沙地被治理”。近似反算来自年度着色 PNG，无法恢复原始浮点栅格。两个五年窗口是 1987—1991 和 2020—2024。

横山和盐池是两个不同的典型窗口，均包含多种地表。窗口变化不能全部归因于单一人物，典型窗口也不能代替整个研究区的统计。不同地点、不同年份的序章新闻照片用于展示治沙场景；它们不是同一地点的治理前、中、后观测。
