# GitHub 整合改动说明 · 2026-10-05

本轮以 GitHub 原发布版 `ba2e0d3` 为底稿，按用户确认的方案整合。用户要求保留原版的优点，并将全部改动、原因、验证与交付状态写进真实 Obsidian Vault。

## 保留的内容

横山首屏两期影像、金绿标题、深色情绪背景、新开场视频、三张实景序章、石光银故事及四位人物照片、四个真实全球案例、手动 BGM、时间轴及故事播放器均沿用。116 个原资产媒体逐字节未变；`main.css`、`editorial.css`、`immersive.css` 内容未变。文字变动可能改变换行，不承诺所有位置像素完全相同。

四条核心年度数组各40个值、共160个值，逐项与原发布版及V2一致；统计锚点、HEADLINE和CHANGE数值没有替换。

## 改动与原因

| 项目 | 具体改动 | 原因 |
|---|---|---|
| 盐池过程观察 | 四组年份配对；建设区轮廓、规则地块、非建设区斑块及全图；两侧同步2.2倍放大 | 已有四景影像值得认真比较，回应“中间发生了什么” |
| 影像生命周期 | 预加载、实际DOM两侧解码、请求序号、失败重试 | 预加载成功不等于实际DOM已解码；防止快速切换错配和标签提前更新 |
| 两个地点 | 横山首屏独立，盐池局部独立；失败不暗换地点 | 保留首屏视觉优势，避免把不同地点当成同一案例 |
| NDVI图例 | 横山灰度−0.2～1；盐池10个实际着色控制点；区域保留0～0.7 | 图例必须对应各自显示产品 |
| 69%等比例 | 改为共同有效图像像元计数，说明未按地面面积加权及PNG近似反算 | 原数字不能直接称为面积或治理成功率 |
| 时间窗口 | 比较1987—1991与2020—2024；低植被子集按1986—1990确定 | 子集定义期与成效比较期作用不同 |
| 年际过程 | 低位波动、上升、高位仍有起伏；同步图表、导览字幕和旁白 | 拟合趋势不代表每一年都上涨 |
| 归因边界 | 停止按颜色直接判断裸沙、城区下降和治理贡献 | 现有结果不含完整地类或因果分析 |
| 外部案例 | 保留四组真实两期影像；示意数字主动展开；乍得湖不配旧萨赫勒比例 | 图片、示意序列和不同指标不能混读 |
| 全球开关 | 默认仍显示；主动关闭时收为单列，打开恢复两列 | 修复强制display与hidden冲突，避免空列 |
| 阅读路径 | 保留故事、自由探索、数据方法；修正模式显隐和方法深链接 | 各入口直接服务对应阅读目的 |
| 文案 | 保留具体人物经历，去掉创作者自我解释与无依据抒情归因 | 去AI味依靠具体事实、动作和地点 |
| 数字动效 | 关键统计直接显示最终数值，保留其他原动效 | 防止截图或快速浏览读到动画中间的虚构统计 |
| 开场 | 补暂停、重播、失败静态末帧、减少动态、重新播放 | 异常情况下画面、年份和提示应一致 |
| 浏览器朗读 | 纠正口径；说明可能联网；取消/异常结束Promise；压低BGM并恢复 | 不能承诺所有语音离线，取消不能阻塞新章节 |
| 素材台账 | 更新发布文件SHA，保留历史记录及C2PA元数据 | 当前照片/影像附加元数据导致完整文件哈希改变，原压缩图像数据未变 |
| AI与团队 | 保留Codex/Claude历史，记录本轮Codex；实际人工复核、分工、录音待填写 | AI实现不能自动变成学生的手写或人工审核贡献 |
| 公开与离线证据 | 去除不存在的tests/tools当前可运行承诺 | 静态仓库不含完整上游处理，旧117项记录与本轮检查分别说明 |
| 演示视频 | 使用最终页面重新捕获、合成旁白、字幕；实际规格见presentation记录 | 旧视频未包含横山首屏与本轮局部交互，需同步 |
| Obsidian | 新建本轮决策、全部文字对照、验收交付记录，链接既有项目入口 | 保留历史，明确修正，方便交付和答辩 |
