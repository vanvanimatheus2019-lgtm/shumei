# GitHub 整合版视频制作说明

本片为 4 分 45 秒中文讲解示范，画面重新捕获自本轮 GitHub 整合页面，原生浏览器视口 1920×900，直接拼入 1920×1080 成片，没有把低分辨率旧网页截图放大。首屏使用横山 1986-08-02 / 2025-08-13 同地点观测，保留“沙、治、绿”实景序章，并展示石光银人物行动、区域时间轴、盐池四期配对及同步观察框。

48 句旁白使用 Windows Microsoft Huihui Desktop：31 句沿用 V2 同文音频，17 句在本机重新合成。它不是团队真人录音；统一按约 1.071 倍节奏整理并加入句间停顿。没有发送旁白到外部语音服务，没有采用授权状态未知的旧背景音乐。独立 SRT 与影片音轨内容一致，另有画面内字幕和 mov_text 字幕轨。

画面中的人物照片和序章照片沿用网页已有材料，保留页面出处与署名。本轮没有取得新闻照片的转载许可。横山、盐池、定边人物案例分别说明，不把典型窗口认领为某一人物的个人林地。不同地点、不同年份的实景照片用于引入，不能当作同地点的前后观测。

区域五年窗口为 1987—1991 和 2020—2024。“约 69%”指共同有效图像像元中近似 NDVI 差值超过 0.1 的计数比例，没有地面面积加权，不是治理面积。全区域序列沿用随附结果，未重新运行原始 GEE；局部单日影像与长时间序列分开。盐池 2000 年单景窗口 NDVI 低于 1986 年，保留波动。不同产品分别看图例，30 米放大不新增地面细节。

实际操作画面通过独立 Chrome 会话捕获：开场播放、横山滑动、区域自动播放和盐池年份/观察框切换。片段按旁白节奏调整时长，仍使用实际界面帧；没有生成遥感细节或模拟不存在的操作结果。

制作与原始音频、截图、操作帧、逐句时序保留在本地交付目录 qa/github-video。网页 presentation 只发布 MP4、SRT、此说明与验证记录。视频使用 H.264 / yuv420p、AAC、faststart，便于公网播放和 Range 拖动。

机器检查包含完整解码、流格式/时长、黑屏检测与音量采样；抽帧目视检查记录及 HTTP Range 以最终验证文件为准。机器检查不能代替团队完整听看、真人录音、人工内容审核或素材许可。
