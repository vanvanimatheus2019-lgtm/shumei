# 绿进沙退｜毛乌素沙地四十年

第十四届全国大学生数字媒体科技作品及创意竞赛参赛作品（数字艺术与可视化设计类）。

在线浏览：[GitHub Pages](https://vanvanimatheus2019-lgtm.github.io/shumei/)。

这是网页运行所需的精简版本。完整工程（数据处理脚本、测试、说明文档、原始影像窗口）在团队的交付包里。

- 影像：Landsat Collection 2（USGS），全区域年度产品与 30 米局部窗口
- 人物资料与照片：新华社、中国绿色时报、国家林草局网站，页面逐条注明出处；照片版权归原作者

2026-10-05 整合保留横山首屏、金绿配色、实景序章、人物故事、全球真实影像与原年度数据。盐池增加四组年份配对和局部同步观察，并修正图例、像元统计、阅读模式和异常处理。
